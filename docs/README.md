# ARGUS Documentation

This directory contains technical and user documentation for ARGUS.

## Structure

```
docs/
├── README.md               # This file
├── architecture/           # Architecture diagrams and deep dives
├── api/                    # API contracts between components
├── guides/                 # Developer and user guides
└── decisions/              # Extended decision records (overflow from DECISIONS.md)
```

## Documentation Standards

- Use Markdown for all documentation
- Include diagrams as Mermaid code blocks (renders on GitHub)
- Keep docs close to the code they describe
- Update docs when changing the code they reference
- Prefer concrete examples over abstract descriptions
