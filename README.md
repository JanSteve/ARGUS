# Verdikt by Soulvai Technologies

> **India's First Multi-Agent Legal AI Platform**  
> Every Indian law. A dedicated agent.

Built with **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**, strictly following the **"Gazette & the Grid"** design system.

---

## 🏛️ Architectural Highlights

- **12 Specialist Agents:** Structured into *Commercial & Regulatory Law*, *Public & Procedural Law*, and *Individual & Social Law*.
- **The "Gazette & the Grid" Aesthetic:** Custom color palette (`ink-navy`, `court-paper`, `seal-oxblood`, `gazette-brass`, `slate`, `verdigris`), editorial serif typography (*Newsreader* + *IBM Plex Sans*), hairline borders, and zero generic emojis.
- **Hero Orchestration SVG:** Live Framer Motion routing diagram demonstrating how queries travel from client to Verdikt Core and domain agents (fully accessible with `prefers-reduced-motion` support).
- **Interactive Directory:** Grouped index table on desktop, touch-friendly accordion on mobile, with instant client-side search filtering.
- **Live Contact Integration:** Client-validated inquiry form with inline error handling.

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### 3. Build for Production
```bash
npm run build
npm run start
```
